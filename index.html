Shorts Pipeline

A personal tool that builds short videos and publishes them to its owner's own YouTube channel.

What it does

Shorts Pipeline runs unattended on a private server. It writes a short script for a chosen topic with a local language model, assembles a vertical video from licensed stock footage, synthesised narration and burned-in subtitles, and uploads the finished file to the YouTube channel belonging to the person who installed it.

Who it is for

This is a single-operator automation tool, not a service for other people. It is installed and run by its owner, on hardware the owner controls, for the owner's own channel. There are no accounts to create and no data is accepted from visitors of this page.

Google account access

  • The only Google permission requested is youtube.upload.
  • It is used for one purpose: uploading videos to the operator's own channel.
  • The resulting credential is stored on the operator's own machine and is never transmitted anywhere else.

See the privacy policy for the full detail.

YouTube API Services

Shorts Pipeline uses YouTube API Services to publish videos. By using it you agree to the YouTube Terms of Service, and the handling of data received from Google APIs is governed by the Google Privacy Policy together with this project's own privacy policy.

Source code

Shorts Pipeline is open source. The code that performs every step described above can be read at github.com/Genexys/shorts-pipeline.
