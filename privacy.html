Privacy Policy

Shorts Pipeline · last updated 7 September 2026

Summary

Shorts Pipeline is a personal, self-hosted automation tool operated by a single person for their own YouTube channel. It has no other users, collects nothing from visitors, and shares no information with anyone.

Information the application accesses

When the operator signs in with Google, the application requests exactly one permission, https://www.googleapis.com/auth/youtube.upload. That permission allows one action: uploading a video file to the channel of the account that granted it. The application does not read the account's videos, comments, subscribers, analytics, profile or email, and it holds no other Google permission.

How the credential is stored

  • The OAuth token is written to a file on the operator's own computer or server and is readable only by the operating-system account that runs the application.
  • It is never uploaded to any third-party service, never included in the published source code, and never sent anywhere except to Google's own API endpoints.
  • Access can be withdrawn at any time at myaccount.google.com/permissions, which immediately makes the stored token useless.

Information collected from other people

None. This website is a set of static pages with no forms, no accounts, no cookies, no analytics and no advertising. The application itself has no sign-up, accepts no submissions from the public, and processes no personal data belonging to anyone other than its operator.

Other services the application uses

To build a video the application contacts stock-footage and text-to-speech providers and runs a language model locally. These requests carry the topic text for the video being produced. They carry no Google account data, no credential and no personal information.

Limited use

Shorts Pipeline's use and transfer of information received from Google APIs to any other app will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

Changes

If this policy changes, the revised version replaces this page and the date above is updated.
